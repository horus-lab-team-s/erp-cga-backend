# Sources consultées — expirations de documents et obligations des CGA

Consultées le 9 novembre 2026, pour le lot 4 (alertes d'expiration). Consigne : « pour les
données dont tu as besoin, réfère-toi à internet, car c'est une activité régulée ; sauvegarde
ce que tu utilises pour comparer. »

Chaque valeur reprise dans le référentiel cite ce fichier et garde le statut `A_VALIDER`
tant que le cabinet ne l'a pas confirmée. **Officiel** = texte ou site de l'administration ;
**secondaire** = site tiers ou document d'un contribuable, à recouper.

## Ce que le référentiel en retient

- `Docs/referentiel/pilotage/expirations.yaml` : l'ACF à 3 mois (`A_VALIDER`, sources 1) ;
  aucun document dont la durée n'a pas été trouvée n'y figure avec une durée — le cabinet la
  saisira.
- Les paliers d'alerte (J-30, J-7, le jour même) sont une politique du cabinet, pas une
  règle : valeurs de départ, réglables.
